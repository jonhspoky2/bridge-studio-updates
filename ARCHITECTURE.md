# Техническая карта

Репозиторий содержит канал доставки и тесты. Исполняемая часть редактора каждого выпуска находится в `updates/v<версия>/studio.html`. Внешний архив Bridge-Studio-v0.18.0-UI-Inventory-Shop-Audio.zip дополнительно содержит src, build_studio.py, C#-хост, установщик, примеры и тесты. Архивный payload v0.18.0 побайтно совпадает с опубликованным HTML этой версии. BridgeLauncher.cs и BridgeUpdateService.cs совпадают между архивами v0.17.2 и v0.18.0. Сборка из старого src без переноса последующих изменений вернёт устаревший интерфейс.

|---|---|
| Windows | BridgeLauncher.cs запускает локальный HTTP-сервер на loopback. Случайный путь с токеном, список допустимых ресурсов, heartbeat и обработка закрытия окна. Three.js r128 кэшируется локально. |

## Play с v0.18.4

Родитель читает исходник выбранной загрузчиком Three.js и встраивает его в документ игры. При наличии локального кэша сеть не нужна. Iframe имеет только allow-scripts, opaque origin и no-referrer. Политика CSP отключает connect, формы, workers, внешние скрипты и вложенные фреймы. Ввод и диагностика передаются через postMessage. Редактор принимает сообщения текущего игрового окна с ожидаемым origin и ограниченным текстом. Stop отзывает blob URL. Sandbox запрещает навигацию верхнего окна. Длительный пользовательский JS всё ещё способен нагружать браузер; лимита CPU нет.

## Воспроизводимая сборка

Из корня репозитория: `python tools/build_studio.py --output studio.html`. Для проверки релиза используйте `python tools/build_studio.py --check updates/v0.18.4/studio.html`. Шаблон, редактор, загрузчик GLB, игровой runtime и оба ядра хранятся в src. Демо-модель хранится в assets. Редактор и игровая сборка получают один исходник каждого общего ядра. Работайте с src, затем собирайте новый каталог версии.

## Terrain v0.19.0 — разделение игрового ядра и редакторских кистей

- `src/terrain_core.js` — общий сериализуемый heightfield v1: `chunks`, проверка швов, одинаковая высота треугольника для рендера и физики. Этот модуль включён в Play/Build.
- `src/terrain_sculpt.js` — **только редактор**: `createFlat`, `begin`, `dab`, `applyPath`, `commit`, `cancel`, `applyCommand`, `refreshMeshes`. **Не входит** в экспортируемую игру, чтобы не раздувать бюджет WARPGAME.
- `src/studio.js` — связка контролов `terrainTab`, Pointer Events и Raycaster с функциями кистей. Состояние активного мазка не сериализуется в проект.
- Для каждого Stroke используется Map мировых узлов и ссылок на копии в соседних чанках; одновременное обновление копий исключает разрывы по границам.
- При каждом мазке в GPU меняются только атрибуты `position` и `normal` чанков, чья геометрия или соседняя нормаль затронуты; `BufferGeometry` не создаётся заново.
- История смешанная: существующие JSON-снимки продолжают работать, команды `kind:'terrain-stroke'` содержат `{chunk,index,before,after}` для изменённых вершин.
- Ключевые ограничения heightfield v1: только поверхность по высотам (нет пещер), максимум 64 чанка/100000 вершин, одинаковое разрешение, высоты [-1000,1000]. Новая панель ограничена картами 1/2/4 чанка в каждой оси.

Не хранить cache/brush nodes в .rwscene и не включать `terrain_sculpt.js` в HTML игры.
