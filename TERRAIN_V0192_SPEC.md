# Bridge Studio v0.19.2 — Terrain Materials & Painting

**Статус:** разработка на базе опубликованной v0.19.1. Рабочая ветка `feature/terrain-materials-v0192`. Не менять подписанный канал патчей до полного CI, проверки реальных WebGL-скриншотов и воспроизводимой сборки.

## Пользовательский сценарий

1. Открыть существующую карту `.rwscene` или создать новый плоский Terrain.
2. Перейти **РЕЛЬЕФ → PAINT**, выбрать «Трава», «Песок», «Земля» или «Камень».
3. Выбрать Radius / Strength / Hardness, провести непрерывный мазок по поверхности.
4. Получить плавные переходы между материалами, без разрывов на границах чанков. Hover показывает контур кисти.
5. Одним Undo/Redo откатить / восстановить целый мазок; Escape откатывает незавершённый мазок и исходное состояние «Сохранено».
6. Сохранить и переоткрыть `.rwscene`, продолжить рисовать и скульптить; Play использует ту же геометрию и раскраску, что Build.
7. Экспортировать WARPGAME HTML; **лимит 3 000 000 байт относится только к готовой игре, не к Bridge Studio**.

## Модель данных

- Сохраняется существующий документ `rwbridge.game`, версия 2, и `terrain.version=1`.
- Каждый чанк *опционально* содержит `weights: number[]`, длина = число вершин × 4. Четыре целочисленных канала 0–255 в порядке grass / sand / dirt / rock, сумма ровно 255.
- Отсутствующие weights в старом проекте трактуются как `[255,0,0,0]` **без миграции документа**. Данные материализации появляются только после реального мазка.
- Для каждой вершины на шве соседних чанков все четыре веса обязаны совпадать; `BridgeTerrainCore.validate` это проверяет.
- Высота и материал независимы: кисть скульптинга не меняет веса, кисть покраски не меняет высоты и коллизии.
- Предельные размеры Terrain остаются прежними: максимум 64 чанка и 100 000 вершин. Проверки NaN, отрицательных/избыточных весов и сумм обязательны.

## Система покраски

`src/terrain_paint.js` — независимое ядро: begin / dab / applyPath / commit / cancel, автоматическая нормализация четырёх каналов, весовой радиальный falloff, атомарные изменения общих вершин, пакетная запись только изменённых чанков. Одинаковые входные данные дают одинаковые значения.

История `terrain-paint` хранит только изменённые вершины и созданные weight-массивы. Undo восстанавливает исходный объект, включая отсутствие weights у старых проектов. Обычные JSON-снимки истории и `terrain-stroke` продолжают работать.

## Рендеринг

`src/terrain_core.js` создаёт для каждого чанка BufferGeometry с атрибутом `terrainWeights`. Все материалы смешиваются в одном `MeshStandardMaterial` через `onBeforeCompile`, с сохранением штатного освещения, теней и PBR-параметров Three.js r128. Текстурный атлас процедурный и генерируется локально при запуске, без сетевых зависимостей. Это первая функциональная фактура, **не финальные пользовательские PBR-наборы высокого разрешения**.

При покраске обновляются только затронутые `terrainWeights` BufferAttributes (`needsUpdate=true`), без пересоздания сцены и GLB. При скульптинге остаётся прежняя инкрементальная логика позиций/нормалей; новые веса не теряются. Для atlas-материала используется одна текстура на Terrain; её освобождение привязано к освобождению материалов.

Тот же TerrainCore включается в редактор, Play и экспорт. Paint Engine в экспорт не включается — игра хранит готовые веса, что экономит HTML-байты.

## Проверки и выходные ворота

- **Unit:** четырёхканальная нормализация, рисование, стирание травой, параметры кисти, отмена и Redo, шов 2/4 чанков, старые проекты, смешивание со Sculpt, скверные веса отвергаются, dirty-чанки.
- **Performance:** 2×2×16 и 4×4×32; P50/P95 расходов времени в Node.js, память/размер сериализованных весов и delta history; реальные FPS на Windows из этого не выводить.
- **Browser:** реальная WebGL-картинка до и после покраски (автоматическая проверка изменения пикселей), четыре палитры, undo/redo, сохранение/открытие, Play/Stop, экспорт и автономный запуск игры без сети; отсутствие исключений.
- **Visual:** отдельно просмотреть скриншоты краёв, общего вида, читаемости травы/песка/земли/камня и отсутствия сетки от повторения atlas.
- **Build:** `python3 tools/build_studio.py --check updates/v0.19.2/studio.html`, SHA-256, контроль 3 МБ экспортированной игры.
- **Release:** PR и зелёный CI, публикация payload через GitHub Pages, затем публикация RSA-подписанного манифеста.
- **Windows:** ручной Smoke Test в Bridge.exe после установки. Не объявлять его успешным без фактической проверки.

## Не входит

Импорт собственных текстурных наборов, физика материалов/разные шаги, 3D-трава, дороги, продвинутые декали, полноценный визуальный материал-редактор и LOD/streaming больших карт. Это отдельные последующие этапы.
