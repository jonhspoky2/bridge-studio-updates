# Технические решения

1. Единица бюджета WARPGAME — байты готового HTML после встраивания данных. Используем консервативные десятичные 3 МБ (3 000 000 байт). Предварительная оценка не разрешает скачивание. Лимит не применяется к редактору, .rwscene или обоим профилям Standalone.
2. Публикуемые каталоги версий неизменяемы. Новое поведение поставляется отдельным подписанным studio.html, а манифест и файл выпускаются одним коммитом. Откат использует штатный маркер предыдущей версии.
3. Сохраняем Three.js r128 и версию 2 .rwscene. При расширении Terrain старые проекты получают пустое состояние по отсутствию поля. Формат независимого блока Terrain и правила миграции утверждаются вместе с тестами чтения.
4. До реализации Terrain не использовать AABB целого чанка как физическую поверхность. Это поставит игрока на высоту самого высокого участка вместо высоты под его ногами.
5. Для неподтверждённых пользовательских игр требуется отдельная граница исполнения. Проверка синтаксиса скрипта и копирование project не дают изоляции. До решения этого вопроса тестовые игры запускаются из доверенных проектов.
