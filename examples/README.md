# Hello Bridge Demo

A simple starter demo scene for Bridge Studio.

## How to use
1. **Play:** Click the green `PLAY` button to test the scene.
2. **Build:** Use the `BUILD HTML` button (WARPGAME - 3 MB profile) to export the game.
3. **Size check:** The exported standalone HTML game is under the 3MB limit.
