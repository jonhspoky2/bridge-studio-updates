## Что входит в v0.19.0

- Отдельная вкладка «РЕЛЬЕФ» с созданием карт 1×1, 2×2, 4×4 участка по каждой оси; тестовый склон оставлен в качестве примера.
- Четыре кисти: Raise, Lower, Smooth, Flatten; Radius, Strength, Hardness; живой контур в 3D.
- Скульптинг мышью, корректная граница между чанками; Escape/pointercancel откатывают текущий мазок.
- Одна операция Undo/Redo на один мазок; компактные изменения вершин, совместимые с обычной историей объектов.
- Инкрементальная запись высот/нормалей в GPU; остальные модели сцены не пересоздаются на каждом движении кисти.
- Сохранение и повторное открытие `.rwscene`; общая поверхность в редакторе, Play и WARPGAME HTML; сохранение формата проекта версии 2.
- Исправлено восстановление статуса «сохранено» при отмене мазка после загрузки проекта.

Код: `src/terrain_core.js`, `src/terrain_sculpt.js`, `src/studio.js`, `src/studio_template.html`.
Спецификация: [TERRAIN_V0190_SPEC.md](TERRAIN_V0190_SPEC.md).

## QA и ограничения

- CI: `.github/workflows/terrain-source.yml`, Node-тесты геометрии и кистей, Chromium + SwiftShader WebGL.
- Browser: создание карты, мазки, Escape, Undo/Redo (включая смешанную историю), сохранение, открытие, Play/Stop, экспорт и запуск WARPGAME HTML.
- Эталонный HTML воспроизводим из `src` побайтно; SHA-256 и размер сверены, RSA подпись манифеста проверена с ключом издателя.
- Предварительный замер на GitHub runner: карта 4×4×32, P95 обновления dirty-чанков снизился с 22,597 до 4,734 мс. Это не тест видеокарты пользователя.
- **Открыто:** Windows smoke test и реальная публикация/игра на платформе WARPGAME. Материальные слои и художественная графика Terrain отсутствуют.
