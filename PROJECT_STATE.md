# Bridge Studio — текущее состояние

## Публикация

- **Последний опубликованный канал патчей:** v0.18.5; Terrain Core и первый тестовый склон.
- **Установка в Windows:** пользователь подтвердил v0.18.2; подтверждения более поздней версии в этом чате нет.
- **Основная ветка:** `main`; в ней находится опубликованный v0.18.5.
- **Разработка:** `feature/terrain-editor-v0190` — рабочая ветка следующего крупного этапа. Манифест обновлений не менять до принятия релиза.

## Разработка v0.19.0: Terrain Sculpting

Детальная спецификация и ворота: [TERRAIN_V0190_SPEC.md](TERRAIN_V0190_SPEC.md).

В рабочей ветке реализовано:
- `src/terrain_sculpt.js`: создание плоских Terrain (1×1, 2×2, 4×4), четыре кисти, мягкая кромка, удержание и интерполяция пути;
- атомарное обновление общих вершин на границах участков;
- компактные Undo/Redo команды с изменёнными высотами;
- обновление только реально затронутых чанков и соседних нормалей в WebGL;
- отдельная вкладка «РЕЛЬЕФ», радиус, сила, жёсткость, круг кисти, отмена через Escape;
- сохранение проекта в исходном `.rwscene` версии 2, Play/Stop и HTML Export через общий Terrain Core;
- скрытие вспомогательной сетки при рисовании и удаление только стандартной стартовой платформы, когда создаётся Terrain.

Автоматизированные тесты:
- `tests/terrain-core.cjs`;
- `tests/terrain-sculpt.cjs`;
- `tests/terrain-sculpt-performance.cjs`;
- `tests/terrain-browser.cjs`;
- `tests/terrain-sculpt-browser.cjs`;
- CI: `.github/workflows/terrain-source.yml`.

Предварительные замеры на GitHub runner: для карты 4×4 чанка по 32 сегмента на чанк P95 обновления геометрии сократилось с **22,597 мс до 4,734 мс** после точного определения затронутых чанков. Это измерение машин CI, а не гарантия FPS на Windows.

## Открытые ограничения / обязательные проверки

1. Итоговый браузерный прогон после последнего UI-рефакторинга, визуальная проверка скриншотов.
2. Smoke-тесты настоящего Bridge.exe на Windows, включая создание рельефа мышью, Undo/Redo, загрузку .rwscene и Play.
3. Окончательные замеры на средних картах и проверка бюджета HTML WARPGAME 3 000 000 байт.
4. Подписанная сборка v0.19.0 и публикация только после выполнения критериев, без обхода защищённого манифеста.
5. Текущая визуализация Terrain — функциональный PBR-базис. Текстурные слои, дороги, трава и более качественные материалы входят в следующий этап v0.19.1, не обещаются частью v0.19.0.
